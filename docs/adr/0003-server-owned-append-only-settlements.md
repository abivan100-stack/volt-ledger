# Server-owned append-only settlements

Completed simulation runs may be accepted by an organisation owner or admin. Acceptance atomically creates immutable, daily per-household settlement events in a server-owned hash-linked ledger, and every event binds the completed run's simulation-result digest and the chosen Monte Carlo outcome. The event's energy is that outcome's synthetic `exportedKwh`; it is not a meter reading or payment. Corrections are represented by subsequent owner/admin-authorized adjustment events, not updates to accepted events. An adjustment carries a signed energy/credit delta, target event, reason, actor, and idempotency key, and inherits the target's settlement provenance. Repeating the same acceptance or adjustment request is idempotent, while accepting a different outcome or reusing an adjustment key with different values is rejected.
