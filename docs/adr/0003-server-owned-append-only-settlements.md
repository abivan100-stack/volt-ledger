# Server-owned append-only settlements

Completed simulation runs may be accepted by an organisation owner or admin. Acceptance atomically creates immutable, daily per-household settlement events in a server-owned hash-linked ledger, and every event binds the completed run's simulation-result digest and the chosen Monte Carlo outcome. The event's energy is that outcome's synthetic `exportedKwh`; it is not a meter reading or payment. Corrections are represented by subsequent adjustment events, not updates to accepted events, so persisted audit history remains trustworthy beyond the client application. Repeating the same acceptance is idempotent, while accepting a different outcome for an already-settled run is rejected.
