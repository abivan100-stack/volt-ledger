## Confirmed findings and repairs

1. High operational: the production Render worker imported the shared production environment schema without `TRUST_PROXY=true`, so it could fail before work began. The blueprint now supplies the setting and has a regression test.
2. Medium deployment: Vercel's CSP allowed only self-hosted scripts while `index.html` contains an inline first-paint theme bootstrap. The policy now includes the exact SHA-256 script hash and a test derives the hash from the file.
3. Medium data isolation: a retained demo child document could outlive its parent run's TTL and allow a known run id to be reused by another session. Demo writes now reject orphaned children belonging to another session.
4. Low determinism: the neighbourhood canvas used `Math.random()` for packet selection and duration, violating the deterministic simulation boundary. It now derives those values from `seededUnit`.
5. Low trust wording: the landing-page ledger CTA called a browser demonstration “tamper-proof.” It now says “tamper-evident,” matching the actual guarantee.
6. High dependency risk: installed Browserslist and fast-uri versions matched current advisories. Compatible lockfile updates now resolve Browserslist 4.28.9, fast-uri 3.1.7/4.1.4, and `npm audit` reports no vulnerabilities.

The existing staged MongoDB collection/index changes were preserved and included in the test runs; they were not rewritten as part of this audit.

`npm audit --json` reported two high-severity package groups: Browserslist and fast-uri (both major-3 and major-4 installed instances). Package advisories alone do not prove an exploitable Volt endpoint. Targeted compatible updates are planned.
